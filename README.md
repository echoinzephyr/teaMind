# teaMind

Windows 11 x64 原生思维导图应用。使用 C# / .NET 10 / WinUI 3 / Win2D，本地优先，无需账号。当前为 **0.1 开发预览版**。

## 启动

打开发布目录中的 `teaMind.exe`。整个目录需一起保留，不要只复制 EXE。发布包包含 .NET 与 Windows App SDK 运行时，无需安装开发工具。发布包尚未签名，也尚未在全新 Windows 虚拟机完成认证。

启动后显示主页：新建导图、最近文件、收藏、本地文件以及当前打开的导图。右键文件卡片可收藏或移除最近记录，移除记录不会删除原文件。文件保存后生成本地预览图。

## 编辑

- 默认以画布为主，大纲、格式和 AI 面板按需展开；点击“专注”收起两侧面板。
- 双击或 F2 编辑节点；Enter 确认，Shift+Enter 换行，Esc 取消。
- Tab 新建子主题，Enter 新建同级主题，Delete 删除，Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。
- Ctrl+C / X / V 复制、剪切、粘贴；Ctrl+A 选择可见节点；Ctrl+F 查找；方向键浏览层级。
- Ctrl+N 新建，Ctrl+O 打开，Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+0 适应窗口。
- 滚轮缩放；空格+拖动或鼠标中键拖动平移；Ctrl+点击多选；空白处拖动框选。
- 节点拖到另一个节点上成为其子节点；Shift+拖动到目标节点上方或下方调整同级顺序。
- 节点右侧圆钮折叠或展开。边界和概要需选择连续的同级主题，关系线需选择两个主题。
- 新增主分支按子树的可见高度选择较空的一侧，并保留已有分支的位置；格式面板的“均衡左右分支”可重新分配，可撤销。
- 编辑过程中点击其他主题会先提交当前文字再切换；输入框沿用节点配色，并随草稿文字增长。
- 图片支持 PNG / JPEG；附件仅提供保存到本地，不自动执行。

## 文件、导出与 AI

`.teamind` 为 ZIP 封装的 JSON 与资源。手动保存使用临时文件替换；更改后空闲两秒生成恢复快照，异常退出后可恢复。数据默认存放在 `%LOCALAPPDATA%\teaMind`；该位置不可写时使用程序目录下的 `Data`。可用环境变量 `TEAMIND_DATA_DIRECTORY` 指定目录。

PNG、SVG、PDF 导出当前画布并保留折叠状态；Markdown 和 Xmind 导出整个文档。导出不添加水印。SVG / PDF 文字使用系统字体轮廓，保证中文外观，文本不可直接搜索或编辑。PNG 支持 1 / 2 / 3 倍清晰度与透明背景；PDF 支持整图与 A4 横向分页。

在设置中填写 OpenAI 兼容服务地址（如带 `/v1` 的前缀）、模型 ID 和 API 密钥。支持兼容的本地模型服务，密钥可留空。三个 AI 入口为文字生成导图、扩展分支、整理总结。生成结果预览确认后才应用，生成整图会新增画布，不覆盖已有内容。AI 服务费用由用户配置的服务决定；密钥使用 Windows 当前用户 DPAPI 加密，不写入导图。

## 当前兼容边界

支持现代 Xmind `content.json` 文件；不支持 Xmind 8 XML。读取多画布、文字层级、备注、显式样式、图片资源、标签标记、超链接、首个附件、自由主题、关系线、边界和概要。保留原始未知字段和资源，导出提供兼容性警告。

**尚未获得真实 Xmind 客户端的完整往返认证，不应视为无损替代品。** Xmind 主题继承、富文本、特殊结构、公式、区域及自定义连线路径无法完整显示或编辑；布局为 teaMind 自有实现，树形图和组织图当前共用纵向树布局，鱼骨图为基础布局。原始数据保留不代表所有编辑后仍可无损还原。多个附件导出为一个主题链接时只映射首个，其余资源保留并提示。

尚未完成屏幕阅读器完整支持、全套高 DPI 人工检查、真实 AI 服务调用及 30 FPS 大图交互认证。AI 已使用模拟 HTTP 响应测试，未配置真实密钥时不会发起付费测试请求。

窗口拖动的卡顿仍在实测和定位。模板选择、样式/画布分栏与节点浮动操作是已记录的后续需求，详见 [开发状态](docs/STATUS.md)。

文件限制：最多 100 画布、50,000 个主题、100 层；解包总大小 256 MB，单个导入附件 20 MB。图片导出限制 16,384 像素单边和 6,400 万像素总面积，超出时建议 SVG / PDF。

## 从源码构建

需要 Windows 11、.NET SDK 10.0.200（或同系列补丁）、Windows SDK 10.0.26100，以及 WinUI XAML 构建工具。Visual Studio 2026 的 WinUI 开发工作负载可提供这些工具。

```powershell
./scripts/build.ps1
./scripts/run.ps1
```

构建脚本使用锁文件还原依赖、运行核心测试并生成自包含发布目录。设置 `MSBuildEnableWorkloadResolver=false` 以避开当前环境的 .NET 工作负载查询异常；不影响此 WinUI 工程的构建。

```powershell
$env:MSBuildEnableWorkloadResolver = 'false'
dotnet run --project tests/TeaMind.Tests/TeaMind.Tests.csproj -c Release -- artifacts/tests
./scripts/run.ps1 -SmokeTest
```

测试夹具为手工构造的现代 Xmind 格式样本，不能代替真实客户端兼容测试。运行验证输出放在 `artifacts`；不提交构建输出与依赖缓存。
